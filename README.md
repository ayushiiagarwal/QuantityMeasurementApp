# 🚀QuantityMeasurementApp

The **Quantity Measurement App** is a Java-based application that supports operations (```unit comparison, unit conversion, arithmetic operations ```) on different physical quantities like ```length, volume, and weight```. It follows clean architecture principles, applies DRY (Don't Repeat Yourself), and evolves feature-by-feature using Git branches.

### Tech Stack
  - Java
  - Spring Boot
  - JDBC
  - MySQL
  - Maven
  - Postman (For API Testing)
